# Vincent Patricio - Personal Portfolio

A responsive personal portfolio website built with HTML and CSS.

## Folder structure
- `index.html` - Main page
- `styles/style.css` - Website styles
- `assets/` - Add your profile photo and other images here

## Before publishing
1. Replace `your-email@example.com` in `index.html` with your real email address.
2. Update the sample project descriptions with your actual school projects.
3. Add a profile picture to `assets/` if desired and update the avatar markup in `index.html`.

## Run locally
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
